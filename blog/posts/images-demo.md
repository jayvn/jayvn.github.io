# Pasting Images Demo

This blog now supports Markdown!

You can write your posts in `.md` files and they will be automatically rendered on the site.

## Adding Images

To add images, you can use standard Markdown syntax:

```markdown
![Image Description](image.png)
```

If you are using an editor like VS Code, you can paste images directly into your markdown file (Ctrl+V). Just ensure the image file is saved in the `blog/posts/` directory (or next to your markdown file).

The blog engine automatically handles relative paths, so `image.png` will look for `blog/posts/image.png`.

## Code Blocks

You can also use code blocks like this:

```javascript
console.log('Hello, Blog!');
```

Enjoy writing!
